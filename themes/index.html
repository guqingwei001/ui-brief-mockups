ThemeForest 候选主题对比

给「UI 设计简报」站挑的 7 个主题,截图来自各自演示站(2026-10-20)。点图看大图。

Typology

WordPress · $59 · 5.6K 销量 · 238 评价

纯文字、无图的极简博客主题。首屏大标题 + 列表,正是“只保留内容”的路子。颜色可改,红只是演示。

最推荐:要做 WordPress 版就选它

Merinda

HTML · $16 · 153 销量

仿 Medium 的个人博客模板,文字优先,带深浅色模式。左主栏 + 右侧热门,结构和“杂志门户”那版接近但更素。

静态站想要一点杂志感就用它

Newsblock

WordPress · $69 · 2.3K 销量 · 2026-08 更新

新闻杂志向,带深色模式,十几套 demo。图多、信息密,偏“新闻网站”。第二张是它的 Tech Rumors demo,更接近科技资讯。

内容量大、想做成门户再考虑

Squaretype

WordPress · $59 · 2.8K 销量 · 2026-09 更新

现代博客,9 套 demo,同一家出品(codesupply)。比 Newsblock 克制一些。

想要卡片式博客的折中选择

Swyft

WordPress · $69 · 1.2K 销量 · 2026-09 更新

主打速度(PageSpeed 98-99)。Journal 和 Devs 两套 demo 偏文字列表,适合每日简报。

在意打开速度就看它的 Journal demo

Katen

HTML · $14 · 309 销量 · 2022 后未更新

Minimal Blog & Magazine,Bootstrap 5。演示站本机打不开,只有 ThemeForest 的小缩略图。

静态站最便宜的现成模板

Blogar

HTML · $13 · 500 销量 · 2025-06 更新

Minimal and clean 博客杂志模板,带深色版。演示站本机打不开,只有缩略图。

Katen 的替代,更新更勤

对照:我做的两版 → 效果 A 纯素清单 · 效果 B 杂志门户
